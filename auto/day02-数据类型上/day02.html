    day02 数据类型（上）¶

    数据类型的概要：

          类     基于str类实例化出来的对象
字符串 str(upper) ："中国"    "日本"    "台湾省"
列表  list ：[1,2,3]   ["王平安","欧阳"]
字典  dict ：{"k1":123,"k2":345}   {"age":"xx","name":"alex"}
元组  tuple
集合  set
布尔  bool
特殊  None
